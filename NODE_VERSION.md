# Configuration Node.js

## ⚠️ Important

Ce projet nécessite **Node.js 16 ou supérieur** car :
- NestJS 10 nécessite Node 16+
- Angular 16 nécessite Node 16+

**Node 14.17.3 ne fonctionnera pas avec ce projet.**

## Si vous voulez quand même utiliser Node 14.17.3

Vous devrez downgrader les versions :
- NestJS 8.x (au lieu de 10.x)
- Angular 13.x (au lieu de 16.x)

## Installer nvm-windows (pour gérer les versions de Node)

1. Téléchargez nvm-windows : https://github.com/coreybutler/nvm-windows/releases
2. Installez `nvm-setup.exe`
3. Redémarrez votre terminal
4. Utilisez :
   ```bash
   nvm install 14.17.3
   nvm use 14.17.3
   ```

## Version recommandée pour ce projet

- **Node.js 18.x ou 20.x** (recommandé)
- **Node.js 16.x** (minimum requis)
